- The agent can rebase a PR (or squash or reword its commits), and `a` force-pushes it: `Force-push 3 commits, up to e0b9581, to eric7h:fix/units, replacing its 2 commits?`. As with any push, only if nobody pushed to the branch since. The worktree keeps the rebase until the PR gets new commits on GitHub, and a rebase stopped on a conflict stays for the agent to finish.
